\section{Why edge was left on the table}
\begin{enumerate}[noitemsep]
  \item \texttt{maxArbPerSlug: 3} but only \textbf{one} \texttt{detectAndExecute} call per market per scan.
  \item Depth loaded only when \texttt{useOrderBookBias}; otherwise synthetic infinite touch ladders.
  \item Equal planned shares on both legs --- not sized from actual Leg1 fill (directional residual risk).
  \item Scan-only reaction; WS book moves did not prioritize fleeting gaps.
\end{enumerate}
